下面是一个打印九九乘法表的 Python 程序示例：

### 九九乘法表

```python
def print_multiplication_table():
    print("九九乘法表：")
    for i in range(1, 10):
        for j in range(1, i + 1):
            print(f"{j} x {i} = {i * j:2}", end="\t")  # 使用格式化输出，使结果整齐
        print()  # 每一行结束后换行

# 调用函数打印九九乘法表
print_multiplication_table()
```

### 代码说明

1. **外层循环**：`for i in range(1, 10)` 迭代数字 1 到 9，表示乘法表的行。
2. **内层循环**：`for j in range(1, i + 1)` 迭代数字 1 到当前行数，表示乘法表的列。
3. **打印格式**：`print(f"{j} x {i} = {i * j:2}", end="\t")` 进行格式化输出，使每个结果的对齐更整齐，`end="\t"` 用于在同一行中输出。
4. **换行**：`print()` 在每一行结束后换行。
