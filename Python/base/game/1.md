这里有一个有趣的程序示例：一个简单的“猜数字”游戏。在这个游戏中，计算机会随机选择一个数字，玩家需要猜测这个数字。游戏会给出提示，告诉玩家猜的数字是高了还是低了，直到猜中为止。

### 猜数字游戏

```python
import random

def guess_number_game():
    print("欢迎来到猜数字游戏！")
    print("我会选择一个 1 到 100 之间的数字，你来猜测。")
    
    number_to_guess = random.randint(1, 100)
    attempts = 0
    
    while True:
        try:
            guess = int(input("请输入你的猜测（1-100）："))
            attempts += 1
            
            if guess < 1 or guess > 100:
                print("请输入一个有效的数字，范围在 1 到 100 之间！")
                continue
            
            if guess < number_to_guess:
                print("太小了！再试一次。")
            elif guess > number_to_guess:
                print("太大了！再试一次。")
            else:
                print(f"恭喜你，猜对了！数字是 {number_to_guess}。")
                print(f"你总共猜了 {attempts} 次。")
                break
        except ValueError:
            print("请输入一个有效的数字！")

# 运行游戏
guess_number_game()
```

### 运行说明

1. **导入库**：程序使用 `random` 库来生成随机数字。
2. **用户交互**：程序会提示用户输入猜测的数字，并根据输入给予反馈。
3. **循环直到猜对**：用户可以不断猜测，直到猜对为止。

### 扩展功能

你可以根据需要扩展这个程序，例如：

- **限制猜测次数**：可以设置一个最大猜测次数，超出则游戏结束。
- **得分系统**：根据猜测次数计算得分。
- **难度选择**：根据用户选择的难度调整数字范围。
