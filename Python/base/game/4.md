# 基于文件的个人记账本
这个工具可以让用户记录和管理他们的开支。用户可以添加记录、查看记录和删除记录，所有数据都保存在文本文件中。

### 1. 显示总开支

计算并显示所有开支的总和，以帮助用户更好地管理财务。

### 2. 按日期记录开支

允许用户输入日期，使得每条记录都有时间戳。

### 3. 分类开支

用户可以为每条开支添加一个类别（如“餐饮”、“交通”等），并能够按类别查看开支。

### 4. 删除记录

允许用户根据记录的序号删除特定的开支记录。

### 5. 保存为 CSV 格式

提供将开支记录导出为 CSV 文件的功能，以便于数据分析和处理。

### 代码示例

```python
import os
import csv
from datetime import datetime

# 文件名
filename = "expenses.txt"


# 函数：添加记录
def add_expense(amount, description, category, date):
    with open(filename, "a") as file:
        file.write(f"{date}, {amount}, {description}, {category}\n")


# 函数：查看记录
def view_expenses():
    if not os.path.exists(filename):
        print("没有找到任何记录。")
        return

    total_expense = 0
    print("开支记录:")
    with open(filename, "r") as file:
        lines = file.readlines()

        if not lines:
            print("没有开支记录。")
            return
        i = 1
        for line in lines:
            date, amount, description, category = line.strip().split(", ")
            total_expense += float(amount)
            print(
                f"{i} 日期: {date}, 金额: {amount}, 描述: {description}, 类别: {category}"
            )
            i += 1

    print(f"总开支: {total_expense:.2f} 元")


# 函数：删除记录
def delete_expense(index):
    if not os.path.exists(filename):
        print("没有找到任何记录。")
        return

    with open(filename, "r") as file:
        lines = file.readlines()

    if 0 <= index < len(lines):
        del lines[index]
        with open(filename, "w") as file:
            file.writelines(lines)
        print("记录已删除。")
    else:
        print("无效的序号。")


# 函数：导出为 CSV 文件
def export_to_csv():
    if not os.path.exists(filename):
        print("没有找到任何记录。")
        return

    with open(filename, "r") as file:
        with open("expenses.csv", "w", newline="") as csv_file:
            writer = csv.writer(csv_file)
            writer.writerow(["日期", "金额", "描述", "类别"])  # CSV 文件的头部
            for line in file:
                writer.writerow(line.strip().split(", "))
    print("记录已导出为 expenses.csv。")


# 函数：主程序逻辑
def main():
    while True:
        print("-------------------------------------")
        print("1. 添加开支")
        print("2. 查看开支")
        print("3. 删除开支")
        print("4. 导出为 CSV")
        print("5. 退出")
        choice = input("请选择操作: ")

        match choice:
            case "1":
                amount = input("请输入金额: ")
                if not amount.strip():
                    print("金额不能为空，请重试。")
                    continue

                description = input("请输入描述: ")
                if not description.strip():
                    print("描述不能为空，请重试。")
                    continue

                category = input("请输入类别: ")
                if not category.strip():
                    print("类别不能为空，请重试。")
                    continue

                date = input(
                    "请输入日期和时间 (YYYY-MM-DD HH:MM:SS)（留空为现在）: "
                ) or datetime.now().strftime("%Y-%m-%d %H:%M:%S")
                add_expense(amount, description, category, date)
                print("开支记录已添加。")
            case "2":
                view_expenses()
            case "3":
                index = int(input("请输入要删除的记录序号: ")) - 1
                delete_expense(index)
            case "4":
                export_to_csv()
            case "5":
                print("退出程序。")
                break
            case _:
                print("无效的选择，请重试。")


if __name__ == "__main__":
    main()

```

### 新增功能说明

1. **显示总开支**：
   - 在 `view_expenses` 函数中计算并显示所有开支的总和。

2. **按日期记录开支**：
   - 用户输入日期，并将其添加到每条记录中。

3. **分类开支**：
   - 用户在添加记录时指定类别，便于后续分析。

4. **删除记录**：
   - 允许用户输入要删除的记录序号，并从文件中删除相应记录。

5. **导出为 CSV 文件**：
   - 提供将开支记录导出为 `expenses.csv` 文件的功能，便于数据处理和分析。
