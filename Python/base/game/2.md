这里有一个使用 `match` 语句的小游戏示例：一个简单的“猜拳”游戏。在这个游戏中，玩家可以选择“石头”、“剪刀”或“布”，计算机会随机选择其中之一，然后根据规则判断胜负。

### 三局两胜的猜拳游戏

```python
import random

# 定义3局2胜
TOTAL = 3
NUM = TOTAL // 2 + 1


def rock_paper_scissors():
    print("欢迎来到猜拳游戏！")
    print("选择你的出拳：")
    print("1. 石头")
    print("2. 剪刀")
    print("3. 布")

    user_wins = 0
    computer_wins = 0
    i = 0

    while user_wins < NUM and computer_wins < NUM:
        i += 1
        user_choice = input("请输入你的选择（1/2/3）：")

        # 将用户输入转换为相应的选项
        match user_choice:
            case "1":
                user_move = "石头"
            case "2":
                user_move = "剪刀"
            case "3":
                user_move = "布"
            case _:
                print("无效输入，请输入 1、2 或 3。")
                continue

        # 计算机随机选择
        computer_choice = random.choice(["石头", "剪刀", "布"])
        print(f"{user_move} | 计算机选择了：{computer_choice}")

        # 判断胜负
        match (user_move, computer_choice):
            case ("石头", "剪刀") | ("剪刀", "布") | ("布", "石头"):
                print("你赢了这一局！")
                user_wins += 1
            case ("剪刀", "石头") | ("布", "剪刀") | ("石头", "布"):
                print("你输了这一局！")
                computer_wins += 1
            case _:
                print("这一局平局！")

        print(f"【{i}/{TOTAL}】当前比分：你 {user_wins} - {computer_wins} 计算机")

    # 最终结果
    if user_wins == NUM:
        print("恭喜你，赢得了游戏！")
    else:
        print("计算机赢得了游戏！")


# 运行游戏
rock_paper_scissors()

```

### 游戏说明

1. **用户输入**：玩家通过输入数字选择出拳（石头、剪刀、布）。
2. **匹配输入**：使用 `match` 语句来将输入转换为对应的文字描述，并处理无效输入。
3. **随机选择**：计算机随机选择出拳。
4. **判断结果**：使用 `match` 语句判断玩家与计算机的出拳结果，输出胜负信息。

### 扩展功能

你可以考虑添加以下功能来增强游戏体验：

- **多局游戏**：让用户可以连续玩多局，记录胜负情况。
- **选择难度**：增加计算机的智能出拳（如根据用户历史记录进行选择）。
- **排行榜**：记录胜利次数并展示给用户。
