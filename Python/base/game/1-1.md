下面是一个小项目的示例：一个猜数字游戏。

### 猜数字游戏

在这个游戏中，程序会随机选择一个数字，玩家需要在指定的范围内猜测这个数字。我们会使用多个函数来组织代码，同时也可以演示如何将游戏逻辑拆分成模块。

#### 游戏代码

```python
import random

# 函数：生成随机数字
def generate_random_number(min_num, max_num):
    return random.randint(min_num, max_num)

# 函数：获取用户输入
def get_user_guess():
    while True:
        try:
            guess = int(input("请输入你的猜测（1-100）："))
            return guess
        except ValueError:
            print("请输入一个有效的数字！")

# 函数：检查猜测
def check_guess(guess, number):
    if guess < number:
        return "太小了！"
    elif guess > number:
        return "太大了！"
    else:
        return "恭喜你，猜对了！"

# 函数：主游戏逻辑
def play_game():
    print("欢迎来到猜数字游戏！")
    number_to_guess = generate_random_number(1, 100)
    attempts = 0

    while True:
        guess = get_user_guess()
        attempts += 1
        result = check_guess(guess, number_to_guess)
        print(result)

        if result == "恭喜你，猜对了！":
            print(f"你总共尝试了 {attempts} 次。")
            break

# 主程序入口
if __name__ == "__main__":
    play_game()
```

### 游戏功能说明

1. **模块导入**：
   - `random` 模块用于生成随机数。

2. **函数设计**：
   - `generate_random_number(min_num, max_num)`：生成一个指定范围内的随机整数。
   - `get_user_guess()`：获取用户输入，并确保输入有效。
   - `check_guess(guess, number)`：比较用户的猜测与目标数字，并返回提示信息。
   - `play_game()`：包含游戏的主要逻辑，调用其他函数来完成游戏的各个步骤。

3. **主程序入口**：
   - 使用 `if __name__ == "__main__":` 语句确保在直接运行脚本时开始游戏。

### 如何使用这个项目

- **函数与模块的概念**：
  - 通过将游戏逻辑拆分成多个函数，学生可以更好地理解函数的作用和重用性。
  - 每个函数负责一个特定的任务，符合单一职责原则。

- **可扩展性**：
  - 学生可以在此基础上扩展游戏功能，比如增加难度级别、记录历史成绩、增加更多的用户反馈等。

- **错误处理**：
  - 使用 `try-except` 结构来处理输入错误，增强代码的健壮性。
